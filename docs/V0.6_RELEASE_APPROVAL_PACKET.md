# v0.6 Release Approval Packet

This document is a release approval packet draft. It organizes the decision
inputs for a future v0.6 release approval. It is not release approval, not a
tag, not a GitHub Release, not external sharing approval, and not a runtime MCP
implementation.

## Purpose

- Gather the release decision inputs in one raw-free document.
- Separate readiness evidence from release action.
- Keep tag and GitHub Release creation behind explicit approval.
- Keep MCP runtime surface closed until a separate approved implementation PR.

## Current Candidate Summary

- v0.5 release baseline exists.
- v0.6 adds operator-facing quickstart, output bundle, Simple Dashboard, RC
  checklist, quickstart smoke, and release notes draft documentation.
- v0.6 keeps the four AI input candidate files unchanged.
- v0.6 keeps candidate finding, draft risk, draft report, and manual
  severity/CVSS boundaries.
- v0.6 does not add automatic ChatGPT handoff.
- v0.6 does not add raw preview or raw download.
- v0.6 does not add replay or active scan behavior.

- [`V0.6_QUICKSTART_SMOKE.md`](V0.6_QUICKSTART_SMOKE.md)

## Approval Criteria

Approval can be considered only if:

- Full gate passes.
- Quickstart smoke passes.
- Simple Dashboard route smoke passes.
- Gitleaks directory scan reports no leaks.
- Gitleaks Git history scan reports no leaks.
- Git safety check passes.
- Release notes draft is raw-free.
- Output bundle four-file structure remains unchanged.
- Manual review requirement remains visible.
- Candidate finding wording remains visible.
- Draft risk wording remains visible.
- Draft report wording remains visible.
- Severity/CVSS manual decision wording remains visible.
- No release blocker is open.

## Required Human Decision

The following remain human decisions:

- Whether to create a v0.6 tag.
- Which commit the v0.6 tag should point to.
- Whether to publish a GitHub Release.
- Whether release notes wording is acceptable.
- Whether candidate finding counts are acceptable as review queues.
- Whether final severity and CVSS have been manually decided outside this
  gateway.

## Security And Privacy Boundary

This packet must not include:

- Raw request or response body.
- Raw audit row body.
- Actual target identifier.
- Actual domain, URL, or IP value.
- Credential value.
- Token value.
- Session value.
- Personal information.
- HMAC secret.
- CSRF token value.
- Full local path.
- Actual local-only filename.

## MCP Status

The following remain not implemented:

- MCP server listener.
- MCP transport.
- MCP protocol handler.
- Executable tool registration.
- Actual tool execution.
- Local evidence reader.
- Safe file body reader.

MCP work remains registry, fixture, dry-run, schema catalog, source-check, and
boundary documentation until a separate approved runtime PR.

## Release Action Status

- Tag created by this packet: no.
- GitHub Release created by this packet: no.
- Release approval granted by this packet: no.
- External sharing approved by this packet: no.
- Next release action requires explicit approval.

## Blockers Before Release Action

- Any final gate failure.
- Any secret scan failure.
- Any raw marker in docs, PR body, or release notes.
- Any full local path in docs, PR body, or release notes.
- Any sharing guarantee wording.
- Any confirmed issue wording.
- Any severity certainty or CVSS certainty wording.
- Any unapproved tag or GitHub Release action.
- Any new MCP runtime surface added without separate review.

## Rollback Plan

If this packet is wrong or stale:

- Revert the documentation PR that introduced this packet.
- Rerun the final gate.
- Refresh the release notes draft.
- Reopen release approval review only after the gate is clean again.
