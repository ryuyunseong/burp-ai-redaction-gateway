## Release Body Hygiene

The release body records v0.10 as a metadata and safety-boundary release for the
MCP transport/listener path.

The release body states that the following remain out of scope:

- transport/listener runtime
- socket bind/listen/accept behavior
- HTTP server runtime
- Streamable HTTP runtime
- stdio subprocess runtime
- protocol handling
- protocol message parsing
- executable tool registration
- actual tool execution
- local evidence reading
- raw preview/download
- replay or active scan
- dashboard state-changing controls
- upload/import actions
- automatic ChatGPT handoff

The release body does not include raw Burp traffic, credential values, target
identifiers, local evidence bodies, stack traces, or local-only file names.
