# VA 점검 분류

VA-01~VA-30은 이 프로젝트에서 사용하는 점검 분류입니다. 코드와 세부 항목은 제공된 목록을 따르며, 분류 등록이 30개 항목의 자동 진단을 뜻하지는 않습니다.

## 결과 읽기

- 검토 후보: 기록의 단서를 해당 VA 점검 분야에 연결했습니다. 취약점 확정이 아닙니다.
- 참고 분류: 해당 분야와 관련이 있을 수 있지만, 현재 단서만으로 취약점을 분류할 수 없습니다.
- 분류 미정: 특정 VA 항목으로 연결하지 않습니다.
- 미점검: 이 기록에서 관련 후보를 만들지 않았습니다. 정상이나 안전을 뜻하지 않습니다.

AI 검토의 항목 선택 화면에서 VA-01~VA-30 분류와 점검 범위를 펼쳐 볼 수 있습니다. 보고서·검토 프롬프트·GUI·CUI는 같은 기준을 사용합니다. 세부 항목을 정할 근거가 없으면 미정으로 남깁니다.
전체 목록의 표시는 분야 단위입니다. 관련 후보가 있어도 그 아래 세부 항목 전체를 검사했다는 뜻은 아닙니다.

## 현재 후보와의 연결

| 현재 점검 후보 | VA 기준 | 표시 |
| --- | --- | --- |
| 객체 접근 권한(IDOR) | VA-11 불충분한 권한 검증 / 수평/수직 권한 이동 | 검토 후보 |
| 쿠키 보호 속성 | VA-16 불충분한 세션 관리 / 세션 쿠키 보안 헤더 설정 미흡 | 검토 후보 |
| 오류 응답 정보 | VA-04 에러 페이지 적용 미흡 / 에러정보 노출 | 검토 후보 |
| 응답 내 민감정보 | VA-05 정보 누출 / 세부 항목 미정 | 검토 후보 |
| CORS·인증 응답 캐시 | VA-05 정보 누출 / 세부 항목 미정 | 참고 분류 |
| 보안 응답 헤더 누락 | 특정 VA 항목에 강제 연결하지 않음 | 분류 미정 |

CORS·캐시는 브라우저 동작과 실제 보호 정보 노출을 확인해야 합니다. 헤더 누락만으로 XSS, CSRF, 평문 전송을 판정하지 않습니다. 오류 상태만으로 내부 정보 노출을, 마스킹 대상 필드가 있다는 이유만으로 불필요한 정보 반환을 확정하지 않습니다.

비밀번호 정책·인증 흐름·업로드·다운로드·자동화 방어·포트·TLS·모바일 앱 등의 항목은 별도 자료와 허가된 수동 점검이 필요합니다. 이 도구는 공격 요청·코드 실행·포트 스캔·Burp 자동 조작을 수행하지 않습니다.

## 전체 분류와 세부 항목

- VA-01 코드 인젝션 (Code Injection): Code Injection
- VA-02 SQL 인젝션 (SQL Injection): SQL Injection
- VA-03 디렉터리 인덱싱: 디렉터리 인덱싱
- VA-04 에러 페이지 적용 미흡: 에러정보 노출
- VA-05 정보 누출: 불필요한 파일 노출 / 서버정보 노출 / Front-End/API 응답 범위 설계 오류 / Config / Secret 정보 노출
- VA-06 크로스사이트 스크립트: 저장형 XSS / 반사형 XSS / DOM 기반 XSS / 설정 미흡 기반 XSS
- VA-07 크로스사이트 요청 위조 (CSRF): CSRF
- VA-08 서버사이드 요청 위조 (SSRF): SSRF
- VA-09 약한 비밀번호 정책: 패스워드 복잡도 정책 준수 미흡 / 기존 패스워드 재사용 / 비밀번호 사용기한 제한 / 계정 초기 패스워드 설정
- VA-10 불충분한 인증 절차: 사용자정보 변경 페이지 접근 시 재인증 절차 없음 / 인증 프로세스 end-point 강제 호출 / 부적절한 입력값 기반 인증 우회
- VA-11 불충분한 권한 검증: 수평/수직 권한 이동 / (mobile) 애플리케이션 영역 권한설정 미흡
- VA-12 취약한 비밀번호 복구 절차: 취약한 비밀번호 복구 절차 / 사용자정보 변경 후 재인증 절차 없음
- VA-13 프로세스 검증 누락: 프로세스 검증 누락
- VA-14 악성 파일 업로드: 웹셸 업로드 / 부적절한 파일업로드 (미실행) / 악성파일 업로드 (정상확장자)
- VA-15 파일 다운로드: 파일 다운로드
- VA-16 불충분한 세션 관리: 부적절한 중요정보 저장 / 세션 쿠키 보안 헤더 설정 미흡 / 세션 유효성 관리 미흡
- VA-17 데이터 평문 전송: 전송구간 암호화 미적용 / 강제 적용 미흡
- VA-18 쿠키 변조: 쿠키 변조
- VA-19 관리자 페이지 노출: 관리자 페이지 외부 노출 / WAS / DB / OS 기본계정 사용 여부 점검
- VA-20 자동화 공격: 자동화 공격 / 패스워드 오류 임계값 미적용
- VA-21 불필요한 Method 악용: 불필요한 웹 메서드 허용
- VA-22 불필요한 포트 오픈
- VA-23 HTTPS 알고리즘 적용 미흡: HTTPS 암호화 설정 미흡
- VA-24 소스코드 난독화 미적용
- VA-25 앱 무결성 검증 미흡
- VA-26 동적 디버깅 가능
- VA-27 루팅, 탈옥단말 실행 차단 미흡
- VA-28 Deeplink 도용 취약점
- VA-29 개발기 외부 노출
- VA-30 2차 인증 우회

표시 순서는 항목 번호 순이며, 심각도나 점검 우선순위가 아닙니다. 이름에 취약점 표현이 있어도 실제 결과는 재현 전까지 검토 후보입니다.

## 기존 결과 사용하기

기존 분석 JSON과 후보 번호는 그대로 읽을 수 있습니다. 새 VA 표시가 들어간 보고서·프롬프트를 만들려면 [사용 방법](USAGE.md)에 따라 새 작업 이름으로 다시 처리하세요. 과거 파일을 자동으로 덮어쓰지 않습니다.

AI 검토는 [전송할 내용을 확인하고 동의](AI_REVIEW.md)한 뒤에만 실행합니다. 원본, 인증 값, 실제 주소를 추가하지 말고 공유 전에 파일 내용을 직접 확인하세요.
