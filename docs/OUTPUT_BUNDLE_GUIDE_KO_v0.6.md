# 결과 파일 안내

결과는 네 파일로 정리됩니다. 처음에는 `report_draft.md`부터 읽고, AI 검토가 필요하면 쓸 파일만 고르세요.
파일을 모두 전달할 필요는 없습니다. 실행 방법은 [사용 방법](USAGE.md)을 참고하세요.

## 파일별 용도

| 파일 | 용도 |
| --- | --- |
| `report_draft.md` | 후보별 발견 내용·확인 방법·조치 제안을 읽는 보고서 초안 |
| `chatgpt_prompt.md` | ChatGPT에 후보 검토를 요청할 때 쓰는 한글 프롬프트 |
| `codex_task_prompt.md` | Codex에 추가 확인 방법과 코드 검토·테스트 항목을 제안받는 한글 프롬프트 |
| `analysis_packet.json` | 후보의 상세 근거·위험도 초안·추가 메모를 담은 분석 데이터 |

프롬프트에는 긴 JSON 대신 발견 내용·판단 한계·확인 방법을 요약했습니다. 후보 번호와 근거 번호로 보고서와 대조할 수 있습니다.
요약에서 생략한 데이터도 민감정보 검사를 거칩니다. 상세 내용은 `analysis_packet.json`에서 확인하세요. 원본 Burp 기록이 아니라 민감정보를 제거한 분석 데이터입니다.

## AI에 전달하기 전

자동 검사가 모든 민감정보를 찾는 것은 아닙니다. 전달 전 직접 확인하세요.

1. 검증이 통과했는지 확인합니다. 검증에 실패한 결과는 사용하지 않습니다. 검사를 끄거나 오류를 무시하지 마세요.
2. 결과 파일 확인에서 내용을 읽고, 후보와 근거가 보고서에 맞게 정리됐는지 확인합니다.
3. 원본 요청·응답, 쿠키·인증 헤더·토큰·세션 값, 개인정보, 실제 URL·도메인·IP와 전체 로컬 경로가 남아 있으면 공유하지 않습니다.
4. 사용할 프롬프트 하나나 필요한 파일·내용만 골라 전달합니다. 결과 폴더 전체를 AI에 올리지 마세요.

점검 항목은 확정 취약점이 아닌 검토 후보이며 위험도는 초안입니다. 실제 취약점 여부와 최종 심각도·CVSS는 재현과 영향 검토 후 직접 판단합니다.
두 프롬프트는 코드 수정·요청 재전송·능동 스캔·외부 전송을 실행하라고 요청하지 않습니다.
이 도구도 요청 재전송, 능동 스캔, 자동 AI 전송은 제공하지 않습니다.

## 파일 찾기와 내보내기

- `process` 명령은 검증 후 네 파일을 결과 폴더의 `ai_candidates/`에 따로 복사합니다.
- 대시보드에서는 파일 4개 내보내기를 누릅니다. 복사된 파일도 내용을 확인한 뒤 사용하세요.
- 파일 상태는 생성 여부를 보여 줍니다. 상세 정보의 크기·수정 시각·해시만으로 공유해도 된다고 판단하지 마세요.
