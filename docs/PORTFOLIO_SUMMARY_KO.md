# 프로젝트 요약

## 만든 이유

Burp 기록을 AI에 전달하면 쿠키·로그인 토큰·개인정보도 함께 넘어갈 수 있습니다.
민감정보를 내 컴퓨터에서 가리고 검사한 뒤, 필요한 자료만 고를 수 있도록 만들었습니다.

## 주요 기능

- XML·JSON·HAR 기록에서 인증정보·실제 대상 주소·개인정보를 가립니다.
- `process` 명령으로 민감정보 제거·검증·보고서 생성을 처리하고, AI 전달 후보 파일 4개를 따로 모읍니다.
- 웹 업로드(XML·JSON)와 대시보드에서 파일을 처리하고 결과를 확인합니다.
- 선택 기능인 [Burp 수집기](MONTOYA_COLLECTOR.md)로 기록을 로컬에 가져오고, [읽기 전용 MCP](READ_ONLY_MCP.md)로 검증된 결과를 읽을 수 있습니다.

## 보안상 한계

- `process`는 검증에 실패하면 처리를 중단하고 전달 후보 폴더를 만들지 않습니다.
- 자동 검사가 모든 민감정보를 찾는 것은 아닙니다. 공유 전 직접 읽고, 원본이나 결과 폴더 전체를 AI에 올리지 마세요.
- 점검 결과는 확정 취약점이 아닌 검토 후보입니다. 실제 재현·영향과 공유 여부는 사람이 판단합니다.
- 원문 조회, 요청 재전송, 능동 스캔, 자동 AI 전송은 제공하지 않습니다. MCP도 Burp를 직접 조작하지 않습니다.
- 공개 예제와 테스트는 가상 자료를 사용합니다. 실제 서비스의 취약점 재현 결과가 아닙니다.
