# 프로젝트 요약

- Burp 기록을 AI에 전달할 때 쿠키, 로그인 토큰, 개인정보가 함께 넘어갈 수 있어 만들었습니다.
- XML·HAR·JSON을 로컬에서 읽고 인증정보, 실제 대상 식별자, 개인정보를 가립니다.
- 검사에서 민감정보가 발견되면 이후 처리를 중단하고 전달 후보 폴더를 만들지 않습니다.
- `process` 명령 한 번으로 검증과 보고서를 만든 뒤 AI 전달 후보 파일 4개를 별도로 복사합니다.
- 웹 업로드와 대시보드에서 결과를 확인할 수 있고, 가상 데이터로 정상·실패 경로를 테스트합니다.
- 점검 결과는 후보로 남깁니다. 실제 재현과 공유 결정은 사람이 하며, 자동 AI 전송은 하지 않습니다.
