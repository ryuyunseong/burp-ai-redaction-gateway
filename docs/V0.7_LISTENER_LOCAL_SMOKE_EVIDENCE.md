# v0.7 Listener Local Smoke Evidence

This document records local smoke evidence for the v0.7 minimal listener
runtime helper. It is release-readiness evidence only. It does not start a
listener, bind a port, implement transport, parse protocol messages, register
or execute tools, read local evidence, or change the four-file AI input
candidate output bundle.

## Purpose

- Fix the local smoke evidence expected from the minimal listener runtime
  helper.
- Keep the smoke evidence raw-free and metadata-only.
- Give later v0.7 RC readiness work a stable evidence input.
- Keep tag and GitHub Release actions out of this PR.

## Current Baseline

The current baseline includes the merged minimal listener runtime helper. That
helper provides disabled-by-default, loopback-only startup validation metadata,
raw-free blocked or disabled responses, status and reason-code allowlists, and
all-interface bind rejection metadata.

The current baseline still does not include long-running listener startup,
socket bind or listen behavior, MCP transport, MCP protocol handling,
executable tool registration, actual tool execution, local evidence reading,
safe file body reading, raw preview, replay, active scan, dashboard
state-changing control, upload or import action, or automatic ChatGPT handoff.

## Smoke Evidence Scope

The smoke evidence is limited to calling the local helper and checking its
metadata. It validates:

- default disabled behavior
- loopback validation metadata
- non-loopback rejection metadata
- all-interface bind rejection metadata
- protocol-like input rejection only when the helper is explicitly enabled
- disabled-first behavior before interpreting caller input
- status and reason-code allowlists
- raw-free blocked or disabled response metadata
- unchanged four-file AI input candidate output bundle metadata

## Consumed Runtime Helper

The consumed runtime helper is:

- `burp_ai_redaction_gateway/mcp_listener_runtime.py`

The smoke fixture consumes the helper through tests. The helper remains a
metadata helper. It does not start a service and does not open transport or
protocol surfaces.
This smoke evidence does not start a listener.

## Expected Smoke Results

Expected smoke results are:

- default disabled smoke passes
- loopback validation smoke passes
- non-loopback rejection smoke passes
- all-interface bind rejection smoke passes
- protocol-like input is blocked only after the helper is explicitly enabled
- disabled helper state returns disabled metadata before input interpretation
- response status values stay allowlisted
- response reason codes stay allowlisted
- `raw_data_included` remains `false`
- `manual_review_required` remains `true`
- `listener_started` remains `false`

## Raw-free Response Checks

The smoke evidence must not include or echo:

- caller body values
- host values
- credential values
- local paths
- stack trace bodies
- safe file body previews
- raw traffic
- target identifiers

Smoke evidence is metadata only. It does not approve external sharing and does
not make any finding final. Final severity and CVSS remain manual decisions.
